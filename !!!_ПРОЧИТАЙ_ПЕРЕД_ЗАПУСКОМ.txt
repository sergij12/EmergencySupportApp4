ЩО ВИПРАВЛЕНО

1. Власна надзвичайна ситуація тепер створюється у розділі "План".
2. Gemini AI генерує конкретні кроки саме під введену НС.
3. Створена НС автоматично з'являється на "Головна" у блоці "Сценарії надзвичайних ситуацій".
4. При натисканні на власну НС з Головної відкривається її план.
5. Якщо Gemini не відповідає або немає ключа, застосунок створює резервний локальний план, щоб не падати.

КУДИ ВСТАВИТИ GEMINI API KEY

Відкрий файл:
local.properties

Встав:
GEMINI_API_KEY=AIzaSy...твій_ключ...
GEMINI_MODEL=gemini-2.5-flash

ВАЖЛИВО

Якщо Android Studio показує помилки після відкриття:
1. Натисни File → Sync Project with Gradle Files.
2. Натисни Build → Clean Project.
3. Натисни Build → Rebuild Project.
4. Якщо застосунок уже був встановлений на емуляторі, видали стару версію з емулятора або очисти дані застосунку, бо база даних була оновлена.


ДОДАНО В ЦІЙ ВЕРСІЇ

1. Власні AI-ситуації можна видаляти:
   - у розділі "План" біля власної НС є іконка кошика;
   - на "Головна" у блоці сценаріїв біля власної НС також є іконка кошика.

2. У розділі "ШІ" виправлено статус "Профіль: 100%":
   - статусні плашки тепер мають горизонтальну прокрутку;
   - текст більше не повинен переноситися по одному слову в стовпчик.

ПІСЛЯ ОНОВЛЕННЯ
Якщо на емуляторі була стара версія застосунку, краще видалити її з емулятора і встановити нову.
